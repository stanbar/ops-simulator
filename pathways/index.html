What this simulator claims

Pathways turns selected OPS terms into explicit logistics mechanics. Oe explores, Oi stabilizes, Di primarily updates private capability, and De primarily updates reciprocal or shared capability. Animal operations prepare pathway state; movement resolves afterward against declared traffic demands.

The simulator tests whether those assumptions produce an intelligible strategy game. It is not evidence that the assumptions describe real people.

Four pathway layers

  • Terrain: what objectively exists.
  • Belief: what each agent currently thinks exists.
  • Personal mastery: what one agent can traverse reliably.
  • Shared pathway: what the expedition can use at scale.

Sleep pays when the same agent later reuses a mastered route. Blast pays when later followers or shared payload reuse established infrastructure. Either investment can be mistimed when no relevant future traffic arrives.
